# Changelog

All notable changes to Silence Splitter are documented in this file.

## [1.0.0-beta.1] - 2026-07-02

### Added

- Silence detection with four editing presets and adjustable timing controls.
- Cut-aware timeline preview with waveform and 48 kHz audio playback.
- DaVinci Resolve and Adobe Premiere Pro exports in OTIO and FCP7 XML formats.
- Codec-copy audio sidecars for every source audio stream.
- French and English interfaces with system, light, and dark themes.
- Windows NSIS installer and GitHub Releases automatic updates.
